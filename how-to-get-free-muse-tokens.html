What are Muse tokens, and why do they matter?

Muse is a personal AI agent: it researches, writes, builds documents and runs tasks for you in a running conversation. Usage is measured against an allowance. On the free plan that allowance is a weekly limit that resets every week — fine for light use, easy to exhaust when Muse is doing real work for you all day.

The invite-code bonus lands in a separate pool called Additional tokens on your Usage page, and it is drawn on after the weekly limit. To show what that looks like on a real account: I run my entire business with Muse — content, book production, job applications, store work. On 24 November 2026 my Usage page showed the free weekly limit at 100% used (it resets 28 November) and my additional-token pool at 71% used with 862 million tokens still left. That pool is the difference between an agent that stops mid-week and one that keeps working.

Step by step: how to redeem the Muse invite code

The whole process takes about two minutes, but the order matters — the code only works on a new account, inside the window.

  1. Create your Muse account at muse.ai/join or in the Muse app. Use your real details; no payment is needed for the free plan.
  2. Go straight to Settings. On the web: Settings → General → Usage → Redeem invite code. In the app: Settings → Redeem token.
  3. Enter the code JPHPHX exactly as written and confirm.
  4. Check your Usage page. You should see the confirmation, and your Additional tokens pool should show the new balance.

Do not put this off until tomorrow. The redemption option closes 48 hours after you join, and a code also stops working once its redemption spots are used up — mine had 28 of 30 left when I checked.

Is Muse free to use?

Yes. Every account gets the free weekly limit whether or not a code is ever redeemed, and the limit resets weekly. The invite code is a one-time bonus on top of that, not a trial and not a subscription trick: there is nothing to cancel afterwards.

Why does the code only work within 48 hours of joining?

Because it is designed as a welcome bonus for new accounts, not a top-up for existing ones. If your account is older than 48 hours, the honest answer is that this route is closed to you — anyone promising a workaround for an old account is selling you something that does not exist. Your free weekly limit still resets every week as normal.

Why is my Muse invite code not working?

Three reasons cover almost every failure:

  • Your account is too old. More than 48 hours since you joined means the window has closed.
  • The code is used up. A standard code allows a limited number of redemptions — 30 for mine — and then stops working for everyone.
  • You already redeemed a code. One bonus per account; a second code will not stack.

If none of those apply, check for a typing error — the code is letters only, and it is not case-sensitive on most screens, but entering it exactly as shown removes the doubt.

Is the 1 billion tokens offer a scam?

The offer itself is a real feature inside Muse’s own Settings — you can open Settings on a new account and see the redemption field with your own eyes before entering anything. What is scammy is the crowd around it: people selling codes that are free, pages asking for card details to “unlock” tokens, and tutorials telling you to hand your password to a stranger. The safe rules are simple: redeem only inside the official app or muse.ai, never pay for a code, and never share your password. My code above costs you nothing and asks for nothing — that is how the genuine offer works.
